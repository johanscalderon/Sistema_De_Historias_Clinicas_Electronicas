Historia Clínica

Esta pantalla permite crear y visualizar historias clínicas utilizando el patrón Composite. La historia clínica funciona como un objeto principal que agrupa diagnósticos y tratamientos dentro de una misma estructura.

Idea del Composite: la historia clínica es el objeto principal y dentro de ella se agrupan diagnósticos y tratamientos como partes del mismo árbol.

El frontend consume endpoints REST del backend Spring Boot.
